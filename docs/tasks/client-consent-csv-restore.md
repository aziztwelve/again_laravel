## Команда для будущего восстановления

`import:restore-client-consents {file}` по умолчанию делает только сверку.
Для записи нужны `--apply --backup=/private/path/new-backup.json`.
Резервная копия содержит идентификаторы и старые/новые флаги, создаётся с
правами 0600 до записи. При изменении согласий после построения плана вся
транзакция откатывается. Пропускаются дубли идентификаторов, конфликтующие
email/телефон и несовпадающие колонки подписки. Политика, оферта, уведомления
о заказе и даты согласий не обновляются.
