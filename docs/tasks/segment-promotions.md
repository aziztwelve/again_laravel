# Акции в сегментах

В карточке сегмента, рядом с промокодами, доступен блок «Акции сегмента».
Кнопка «Добавить / убрать акции» открывает поиск существующих акций; выбор
сохраняется между страницами списка. Сохранение заменяет набор привязок атомарно
через `PUT /api/segments/{segment}/promotions` (`promotion_ids: []` удаляет все).
Только авторизованный сотрудник может менять привязки.

## Доступность

- Акция без сегментов остаётся общей, как раньше.
- При наличии привязок акция доступна клиенту из хотя бы одного **активного**
  сегмента. Только неактивные сегменты никому доступ не дают.
- Используется сохранённый состав сегмента. Он меняется при существующем
  автоматическом/ручном пересчёте и ручном добавлении/удалении клиентов.
- Даты акции, лимиты, сумма, товары-триггеры, подарки, приоритет и совместимость
  с другими акциями/промокодами продолжают работать по прежним правилам.
- Гость не получает сегментные акции. Подстановка client_id или email клиента
  не даёт доступ: витрина использует личность из проверенного Sanctum-токена.
- При создании заказа сотрудником проверяется выбранный client_id. При смене
  клиента админка сбрасывает выбор подарков и заново проверяет акции.
- Перед записью подарка/списанием остатка сервер повторно проверяет доступ.
- Удаление последней привязки (в том числе удаление самого сегмента) делает
  акцию общей. Если требуется полностью выключить её, выключите саму акцию.

Данные хранятся в `promotion_segment` с уникальной парой ключей и FK.
Копии прав на клиентов не создаются: доступ проверяется по актуальной связи.
