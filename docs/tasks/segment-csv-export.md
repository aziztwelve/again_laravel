# Экспорт сегментов в CSV

В карточке сегмента доступна кнопка «Экспорт CSV», в списке сегментов —
иконка выгрузки. Диалог предлагает полный список, Email или WhatsApp,
выбор ручных/автоматических участников, 17 полей и разделителя `;` либо `,`.
Предпросмотр показывает первые 10 строк, количество строк файла и причины
исключений. Изменение настроек сбрасывает предпросмотр; скачивание доступно
после непустого предпросмотра.

Полный список сохраняет участников без контактов и повторяющиеся контакты.
Для Email и WhatsApp по умолчанию включены фильтр подписки и удаление
повторов. Email приводится к нижнему регистру, телефон — к международной
записи с `+`; проверяется формат, но не регистрация номера в WhatsApp.
При повторе остаётся первый подходящий клиент по ID.

Подписка WhatsApp хранится отдельно в `clients.subscribed_to_whatsapp`
и доступна при создании/редактировании и просмотре карточки клиента.
Для существующих клиентов её начальное значение false. Подписка Email
и уведомления о заказах не считаются подпиской WhatsApp.

Файл содержит только разрешённые поля: ID, ФИО, Email, телефон, дату рождения,
адрес, регистрацию, количество/сумму покупок, средний чек, сегмент,
способ/дату добавления, подписки Email/WhatsApp, согласие ПДн и теги.
Статистика покупок учитывает оплаченные доставленные заказы за всё время,
исключая удалённые, и соответствует статистике карточки сегмента.
Выгружается текущий состав, включая ручное закрепление; экспорт не запускает
пересчёт. Предпросмотр и файл — отдельные запросы, поэтому изменения состава
между ними могут изменить результат.

API сотрудника:

- GET `/api/segments/{segment}/export-preview`
- GET `/api/segments/{segment}/export`

Параметры: channel=all/email/whatsapp, origin=all/manual/auto,
columns[], delimiter, consent_only=0/1, deduplicate=0/1.
Для каналов обязательно поле соответствующего контакта. Неизвестные,
пустые и повторяющиеся поля отклоняются. Покупателю доступ закрыт.
CSV содержит UTF-8 BOM, корректное экранирование и защиту текстовых ячеек
от формул таблиц. Порядок заголовков совпадает с порядком значений.
Чтение клиентов выполняется порциями с агрегатами заказов без N+1.

повторы, нормализация телефонов, обе причины включения, пустые данные,
удалённые клиенты/заказы, статистика, лимит предпросмотра, формулы,
права доступа, валидация и число запросов.

HTTP-запрос с временным токеном сотрудника проверил CSV WhatsApp: 200,
BOM, заголовки, количество строк и совпадение значений с предпросмотром.
