# Интеграции

Здесь описаны внешние сервисы, с которыми работает бэкенд: как устроена интеграция,
какие данные нужны для подключения, где они хранятся, что уже проверено и что нет.

Секреты (токены, пароли, ключи) в документацию **не записываем** — только названия
переменных и места, где они лежат.

| Файл | Интеграция | Состояние описания |
|---|---|---|
| [moysklad.md](moysklad.md) | МойСклад (каталог, остатки, заказы, отгрузки) | готово |
| [cdek.md](cdek.md) | СДЭК (ПВЗ, расчёт, заявки, треки) | готово |
| yandex-delivery.md | Яндекс.Доставка | планируется |
| yandex-pay.md | Яндекс Пэй | планируется |
| [cloudpayments.md](cloudpayments.md) | CloudPayments | готово |
| robokassa.md | Robokassa | планируется |
| [whatsapp.md](whatsapp.md) | WhatsApp (сообщения, фото, голосовые, видео) | готово |
| messengers.md | Telegram, MAX, VK | планируется |
| yandex-maps.md | Яндекс.Карты (ключ JS API, геокодер) | планируется |

Состояние боевых и тестовых режимов, список недостающих данных и порядок подключения
по каждой интеграции ведём в её файле, в разделах «Состояние» и «Не проверено / что сделать».
